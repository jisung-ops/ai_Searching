# Code Verification & Self-Fix Helper Skill

이 스킬은 작업 시 코드를 수정하거나 새로운 기능을 추가한 직후, 결과를 직접 테스트하고 스스로 오류를 해결하기 위해 필수적으로 적용해야 하는 검증 지침입니다.

## 핵심 수행 지침

1. **자가 테스트 무조건 실행**:
   - 코드 수정 또는 신규 기능 구현 후, 완료 선언 및 사용자 보고를 하기 전에 **반드시 검증 명령(예: `npm run build`, 컴파일 및 런타임 오류 검사)**을 실행하여 테스트를 수행합니다.

2. **테스트 통과 시 (정상 작동)**:
   - 검증 테스트가 오류 없이 한 번에 성공(Exit Code 0)하면, 추가적인 코드 변경 없이 결과를 마무리하고 `git-commit-helper` 지침에 따라 깃 커밋 추천 단계로 진행합니다.

3. **문제 발생 시 (셀프 픽스 & 재검증)**:
   - 빌드 실패, 타입 에러, 구문 오류 또는 로직 문제가 확인될 경우 사용자에게 질문을 넘기지 않고 **스스로 로그와 원인을 분석하여 즉시 수정**합니다.
   - 수정 완료 후 다시 검증 테스트를 재실행하여 정상 작동을 완전히 확인할 때까지 이 과정을 반복합니다.
